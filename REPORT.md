# ОТЧЕТ ПО РАЗРАБОТКЕ ИГРЫ МАРИО НА C++

## 1. ВВЕДЕНИЕ

### 1.1 Цель проекта
Разработка консольной игры в стиле классического платформера Марио с использованием языка программирования C++.

### 1.2 Задачи
- Реализовать игровую механику платформера
- Создать систему управления персонажем
- Реализовать физику движения и прыжков
- Добавить игровые объекты (препятствия, монеты)
- Реализовать систему подсчета очков и жизней

## 2. ТЕХНИЧЕСКИЕ РЕШЕНИЯ

### 2.1 Выбор технологий
- **Язык программирования**: C++ (стандарт C++11)
- **Компилятор**: g++/MinGW
- **Платформа**: Windows (использование windows.h для работы с консолью)
- **Библиотеки**: 
  - `windows.h` - для управления консолью и курсором
  - `conio.h` - для обработки ввода с клавиатуры
  - `vector` - для хранения динамических массивов объектов
  - `iostream` - для ввода/вывода

### 2.2 Архитектура приложения

Проект построен на объектно-ориентированном подходе и включает следующие основные классы:

#### 2.2.1 Класс Mario
Отвечает за персонажа игрока:
- **Атрибуты**: координаты (x, y), скорость по вертикали, флаг прыжка, очки, жизни
- **Методы**: 
  - `jump()` - инициирует прыжок
  - `update()` - обновляет физику движения
  - `moveLeft()`, `moveRight()` - горизонтальное движение

#### 2.2.2 Класс Obstacle
Представляет препятствия на пути игрока:
- **Атрибуты**: позиция, ширина, флаг активности
- **Методы**: `move()` - движение препятствия влево

#### 2.2.3 Класс Coin
Представляет собираемые монеты:
- **Атрибуты**: позиция, флаг активности
- **Методы**: `move()` - движение монеты влево

#### 2.2.4 Класс Game
Главный класс, управляющий игровым процессом:
- **Атрибуты**: экземпляр Марио, векторы препятствий и монет, счетчик кадров
- **Методы**:
  - `run()` - основной игровой цикл
  - `update()` - обновление состояния игры
  - `draw()` - отрисовка игрового поля
  - `handleInput()` - обработка ввода
  - `checkCollision()` - проверка столкновений
  - `collectCoins()` - сбор монет
  - `spawnObstacle()`, `spawnCoin()` - генерация объектов

### 2.3 Игровая механика

#### 2.3.1 Физика прыжков
Реализована простая физическая модель:
- При прыжке персонажу задается начальная отрицательная скорость (-3)
- Каждый кадр скорость увеличивается (гравитация)
- При достижении уровня земли персонаж останавливается

#### 2.3.2 Система столкновений
Проверка столкновений выполняется путем сравнения координат:
- Для каждого активного препятствия проверяется совпадение позиции с Марио
- При столкновении уменьшается количество жизней
- Если жизни заканчиваются - игра завершается

#### 2.3.3 Генерация объектов
Случайная генерация препятствий и монет:
- Препятствия появляются с вероятностью 2% каждый кадр
- Монеты появляются с вероятностью 3% каждый кадр
- Монеты размещаются на разной высоте для разнообразия

#### 2.3.4 Система очков
- За каждую собранную монету начисляется 10 очков
- Очки отображаются в нижней части экрана
- Финальный счет показывается при завершении игры

## 3. РЕАЛИЗАЦИЯ

### 3.1 Структура кода
Код организован в один файл `mario.cpp` для простоты компиляции и содержит:
- Объявления классов
- Реализацию методов
- Главную функцию main()

### 3.2 Константы игры
```cpp
const int WIDTH = 40;          // Ширина игрового поля
const int HEIGHT = 20;         // Высота игрового поля
const int GROUND_LEVEL = 17;   // Уровень земли
```

### 3.3 Визуализация
Игра использует ASCII-графику:
- `M` - Марио
- `#` - Препятствия
- `O` - Монеты
- `=` - Земля

### 3.4 Управление консолью
Использованы функции WinAPI для:
- Скрытия курсора (улучшение визуала)
- Позиционирования курсора (обновление экрана без мерцания)
- Установки кодировки для поддержки русского языка

## 4. ОСОБЕННОСТИ РЕАЛИЗАЦИИ

### 4.1 Оптимизация производительности
- Очистка неактивных объектов из векторов
- Использование setCursorPosition вместо system("cls") для уменьшения мерцания
- Задержка 50мс между кадрами для стабильной частоты обновления

### 4.2 Поддержка русского языка
Установка кодовой страницы Windows-1251:
```cpp
SetConsoleCP(1251);
SetConsoleOutputCP(1251);
```

### 4.3 Игровой баланс
- Начальное количество жизней: 3
- Очки за монету: 10
- Начальная позиция Марио: (5, GROUND_LEVEL)
- Сила прыжка: -3 (позволяет перепрыгивать препятствия)

## 5. ТЕСТИРОВАНИЕ

### 5.1 Проверенные сценарии
- ✓ Движение персонажа влево/вправо
