# Игра Марио на C++

## Описание

Простая консольная игра в стиле Марио, написанная на C++. Игрок управляет персонажем Марио (M), который должен собирать монеты (O) и избегать препятствий (#).

## Возможности

- Управление персонажем (движение влево/вправо, прыжки)
- Система очков за сбор монет
- Система жизней
- Динамическая генерация препятствий и монет
- Обнаружение столкновений

## Требования

- Компилятор C++ (g++ или MinGW для Windows)
- **Кросс-платформенная поддержка**: работает на Linux, macOS и Windows
- Make (опционально, для использования Makefile)

## Компиляция

### Вариант 1: Используя Makefile
```bash
make
```

### Вариант 2: Напрямую через g++
```bash
g++ -std=c++11 -o mario mario.cpp
```

### Для Windows с MinGW:
```bash
g++ -std=c++11 -o mario.exe mario.cpp
```

## Запуск игры

### Linux/macOS:
```bash
./mario
```

### Windows:
```bash
mario.exe
```

### Или используя Makefile:
```bash
make run
```

## Управление

- **Пробел** - прыжок
- **A** - движение влево
- **D** - движение вправо
- **Q** - выход из игры

## Правила игры

1. Собирайте монеты (O) для получения очков (+10 очков за монету)
2. Избегайте препятствий (#)
3. При столкновении с препятствием вы теряете одну жизнь
4. У вас есть 3 жизни
5. Игра заканчивается когда заканчиваются все жизни

## Очистка

Для удаления скомпилированных файлов:
```bash
make clean
```

## Структура проекта

- `mario.cpp` - основной файл с кодом игры
- `Makefile` - файл для автоматической сборки
- `README.md` - этот файл с инструкциями
- `REPORT.md` - отчет о проекте

## Технические детали

Игра реализует:
- Объектно-ориентированный подход (классы Mario, Obstacle, Coin, Game)
- Физику прыжков с гравитацией
- Систему обнаружения столкновений
- Динамическую генерацию игровых объектов
- Консольную графику с использованием ASCII символов
- **Кросс-платформенность**: автоматическое определение ОС и использование соответствующих API
  - Windows: использует `windows.h` и `conio.h`
  - Linux/macOS: использует POSIX API (`termios.h`, `unistd.h`)
